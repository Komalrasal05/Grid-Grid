.blog-demo {
  display: grid;
  grid-template-columns: 190px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.blog-main { grid-area: main; }

ASSIGNMENT 3

Responsive Gallery

Use auto-fit and minmax() to fit the screen.

.gallery-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-areas:
    "blueberries strawberries watermelon watermelon"
    "grapefruit grapefruit watermelon watermelon"
    "papaya papaya pineapple pineapple";
  gap: 12px;
}
.fruit-blueberries { grid-area: blueberries; }
.fruit-strawberries { grid-area: strawberries; }
.fruit-watermelon { grid-area: watermelon; }
.fruit-grapefruit { grid-area: grapefruit; }
.fruit-papaya { grid-area: papaya; }
.fruit-pineapple { grid-area: pineapple; }
@media (max-width: 700px) {
  .gallery-grid {
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
    grid-template-areas: none;
    grid-auto-rows: 150px;
  }
  .gallery-grid figure { grid-area: auto; }
}
